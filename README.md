# hogsmeade

мастерская каталогов и доставок. версия 2.1.0.

- `rich-peach/` — отдельная мастерская пича, каталог, шаблоны и изображения.
- `under-the-raven-wing/` — отдельная мастерская Ворона.
- `cafeteria/` — пустая мастерская будущего кафетерия.
- `shared/` — общий код, font awesome и исходное оформление.
- `migration/image-links.json` — соответствия старых и новых адресов, контрольные суммы файлов.

## публикация

создать публичный репозиторий raven-hd/hogsmeade с readme. загрузить содержимое этой папки в корень ветки main. в settings → pages выбрать deploy from a branch → main → / (root). адрес: https://raven-hd.github.io/hogsmeade/ .

для проверки на компьютере: `python3 -m http.server 8000`, затем http://localhost:8000/ . открытие index.html через file:// не поддерживает загрузку json: используйте локальный сервер или опубликованный сайт.

## работа с github

при первом открытии магазин загружает свой data.json. локальные правки сохраняются в браузере; для отправки нажать «сохранить на github». верхняя кнопка github открывает подключение. нужен fine-grained token только для этого репозитория, contents: read and write. в окне подключения есть галочка «запомнить токен на этом устройстве». с ней токен сохраняется в браузере, восстанавливается после обновления страницы и используется всеми магазинами этого репозитория. без галочки он действует только в открытой вкладке до перезагрузки. токен хранится отдельно от настроек каталога и не включается в резервные копии, data.json, users.json или код проекта. кнопка «отключить токен» удаляет сохраненный токен и отключает его в других открытых вкладках этого репозитория. для другого репозитория используется отдельное подключение. на новом устройстве каталог доступен без токена; токен нужен для записи и загрузки новых картинок.

каталог, шаблоны, профили доставки, параметры каталога и реестр артикулов записываются одним документом. сохранение использует sha реально загруженной версии. при изменении с другого устройства запись останавливается. сначала скачать полную резервную копию локальных правок, затем загрузить свежий каталог и перенести нужные изменения. автоматического слияния нет. если во время записи продолжать редактировать, более поздние правки останутся несохраненными и потребуют следующего сохранения.

новая картинка загружается при выборе файла сразу; ссылка вставляется в форму. имя включает постоянный артикул и уникальную версию. при замене сохраняется прежний файл: старые доставки продолжат показывать прежнее изображение. после загрузки сохранить карточку, затем каталог на github. отмена формы оставляет неиспользованный файл, но не переиспользует его артикул.

полная резервная копия остается доступна верхней кнопкой скачивания. старые форматы импорта поддерживаются. «база пользователей» → «загрузить» принимает полную резервную копию магазина или отдельный файл людей; товары при этом не меняются.

## общая база пользователей

общая база хранится в `shared/users.json` и загружается при открытии любого магазина на любом устройстве. первоначальные 53 записи перенесены из проверенной резервной копии от 19 октября 2026 года. имена, ID и ссылки форума опубликованы с согласия владельца; файл доступен всем, как и сам репозиторий.

добавления, исправления и удаления отправляются автоматически через секунду после изменения, если подключен токен через «магазин · github». без токена изменения остаются в браузере и ожидают подключения. при включенной галочке повторный ввод токена после перезагрузки не требуется; импортировать базу заново тоже не нужно. статус в окне базы показывает результат сохранения; стрелки позволяют обновить ее вручную.

изменения разных записей объединяются. при несовместимых правках одной записи автоматическая отправка останавливается; локальная версия сохраняется. ее можно скачать, затем загрузить версию github кнопкой обновления. перед подтвержденной заменой сохраняется дополнительная копия в браузере (`delivery.v2.recovery.users`). обновление использует sha прочитанного файла; запросы из вкладок одного браузера сериализуются через Web Locks. при ошибке связи или доступа локальная база не удаляется.

## данные и изображения

источник каталогов — проверенные пользователем резервные копии от 19 октября 2026 года: 76 товаров пича и 128 товаров Ворона. порядок, группы, серии, описания, цены, шаблоны и идентификаторы сохранены. добавлены постоянные артикулы и обновлены ссылки на скопированные изображения. оригинальные файлы изображений не пережимались. в архиве соответствий приведены sha256.

старые репозитории и файлы не изменялись. копирование не меняет ссылки в уже опубликованных сообщениях. не удалять прежние источники до замены всех нужных ссылок. дополнительные инструменты пича (конструкторы и декодер), не входящие в генератор доставок, пока остаются на прежнем месте.

в витринах заменять ссылки по image-links.json, учитывая варианты github.com/blob/...?... и raw.githubusercontent.com. исходный bbcode витрин еще не предоставлен. не делать глобальную замену домена: категории и имена файлов менялись.
